## 数据与兼容

- 保持原有 JSON 格式与字段兼容；旧 `followed.json` 没有 `archived` 时仍视为正在追番。不自动迁移 SQLite。
- 发布版的数据根目录是程序所在目录；`wails dev` 的 `build/bin` 程序使用项目根目录，`go run`/测试使用工作目录。可用 `ULTIMATEANIME_DATA_DIR` 指定根目录，建议使用绝对路径。
- 从旧版本升级时，将原来的 `config.json`、`followed.json`、`cache` 和相对路径指向的下载文件放在同一数据根目录。若以前从其他工作目录启动，可用上述环境变量继续使用旧目录，无需移动文件。
- `config.json`、`followed.json`、`downloads.json` 每次覆盖前保留一份有效的 `.bak`。遇到损坏文件停止写入并显示错误；退出应用、保留损坏原件，再将对应 `.bak` 复制回原文件名后重启。备份与任务文件已加入 `.gitignore`。
- 下载目录变更只影响新建任务，重试仍使用原任务目录。修改账号/代理不改变已在传输的任务绑定。
- 重启后的活跃任务显示“已中断，可继续”。用户在任务中心点击重试后，已有云端任务继续查询，已有文件 ID 直接继续本地传输。只有明确失败的云端任务在重试时重新创建。第二阶段已增加跨重启分块续传，复用经 SHA-256 校验的完整分块。
- 视频完成但索引写入失败时保留任务路径及 `local_ready`，重试先验证文件并补写索引，不重复传输。
